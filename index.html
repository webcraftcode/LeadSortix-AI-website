The Core Workflow

The Dual-Channel Conversion Engine

One inbound form. Two specialized conversion branches. Never leave high-paying emergency callers waiting, and never waste time coordinating consultation schedules.

Stage 01
1. Form Intercept
Submission captured via native hooks (CF7, Elementor, WPForms). Payload sanitized with WordPress nonce & Anti-DDE.
Stage 02 • <350ms
2. AI Urgency Triage
Multi-provider models classify sentiment, dollar value, and danger criteria. Generates an urgency score from 0 to 100.
🚨 Branch 1: High Urgency (Score > 75)
Hotline Trigger
Triggers glowing phone hotline auto-dialer for dispatchers, sends emergency SMS alerts, and marks lead as RED in WP Admin.

Calendar Route
Dispatches personalized AI draft via Resend REST API with embedded Cal.com / Calendly instant booking link.

Developer & Setup Resources

Up and Running in 3 Minutes

Get started immediately via WordPress Admin or automate via WP-CLI and cURL Webhook integrations.

1
Install & Activate Plugin
Search for LeadSortix AI inside your WordPress Plugin Directory (or run WP-CLI) and click Activate.
2
Paste Any AI Provider Key
Add your Google Gemini (Free), Groq, OpenAI, Claude, or xAI API key. Or select the offline heuristic mode with zero keys required.
3
Set Hotline & Calendar URL
Enter your emergency operator phone number and paste your Cal.com / Calendly consultation link. That's it—triage is active!
cURL REST Webhook Request 
curl -X POST https://yourdomain.com/wp-json/leadsortix/v1/triage \
  -H "Content-Type: application/json" \
  -H "X-LSX-Secret: lsx_sec_live_99214a" \
  -d '{
    "name": "Sarah Jenkins",
    "phone": "+15553829912",
    "email": "sarah@example.com",
    "message": "Urgent: burst pipe upstairs leaking water!"
  }'
WP-CLI Rapid Deployment 
# Install and activate LeadSortix AI via WP-CLI
wp plugin install leadsortix-ai --activate

# Set default emergency hotline & provider
wp option update leadsortix_hotline_phone "+18005557582"
wp option update leadsortix_ai_provider "groq"
